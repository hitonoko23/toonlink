# 財務指標ビジュアライザー

ROE・EPS・PER・PBR の関係を、ブラウザ上でスライダー操作しながら学べるシンプルなWebアプリです。

## 使い方

1. `index.html` をブラウザで開く。
2. 入力スライダー（純利益・自己資本・発行済株式数・株価）を動かす。
3. 指標カードとバー表示で、各指標の変化を確認する。

## 指標の定義

- ROE = 当期純利益 ÷ 自己資本
- EPS = 当期純利益 ÷ 発行済株式数
- PER = 株価 ÷ EPS
- PBR = 株価 ÷ BPS
- BPS = 自己資本 ÷ 発行済株式数

加えて、`PBR ≒ PER × ROE（ROEは小数）` の関係も画面内で確認できます。
